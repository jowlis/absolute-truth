Verify it yourself

Every cycle's record is hashed together with the hash of the cycle before it. If anyone changed a past cycle, its hash and every hash after it would no longer match.

How to check

  1. Download data/cycles.json (every cycle's full record) and verify_chain.py (40 lines, standard Python only).
  2. Run python verify_chain.py cycles.json. It recomputes every hash and says whether the chain is intact.
  3. Compare the latest hash with one you noted earlier: if they match, no history before it was rewritten.

All findings with their history are also available as data/findings.json.
