F0101 supported

The domain assumptions for Tsirelson's bound are: (a) a bipartite Hilbert space ℋ = ℋ_A ⊗ ℋ_B of arbitrary finite or infinite dimension; (b) Hermitian operators A₁, A₂ on ℋ_A and B₁, B₂ on ℋ_B with spectra contained in {-1, +1} (i.e., A_i² = I, B_j² = I); (c) the CHSH operator is C = A₁⊗B₁ + A₁⊗B₂ + A₂⊗B₁ - A₂⊗B₂. The bound |⟨C⟩| ≤ 2√2 is saturated if and only if the state is a maximally entangled two-qubit state (locally equivalent to the singlet) and the observables satisfy the anti-commutation relations {A₁,A₂} = 0, {B₁,B₂} = 0 with appropriate relative angles (e.g., 45° between A₁,A₂ and 22.5° between Bob's settings and Alice's).

Review note
The claim precisely specifies the domain assumptions (bipartite Hilbert space ℋ_A ⊗ ℋ_B, spectrum in {-1, +1}) and the saturation conditions (maximal entanglement, anti-commuting observables) for Tsirelson's bound.

Evidence

Standard quantum information textbook derivation (e.g., Nielsen & Chuang, Wilde). The operator norm bound gives ⟨C⟩² ≤ 4 + [A₁,A₂]⊗[B₁,B₂]. For ±1 observables, [A₁,A₂] = 2i A₁A₂ when they anti-commute, giving norm 2. Maximum ⟨C⟩² = 8. Saturation requires the state to be an eigenstate of the operator achieving the norm, which forces maximal entanglement and specific anti-commutation relations. Higher dimensions reduce to qubit subspaces via Naimark dilation.
