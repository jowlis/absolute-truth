F0020 supported

Rice's Theorem: Any non-trivial semantic property of partial computable functions (a property S of partial functions that is neither empty nor includes all partial computable functions) is algorithmically undecidable; specifically, the index set { e | φ_e ∈ S } is not computable. Domain boundaries: Applies strictly to semantic (input-output behavior) properties of partial computable functions; does not apply to syntactic properties of program code (e.g., code length, AST structure, specific instruction counts) or trivial properties (empty set or universe).

Evidence

Proved by H. Gordon Rice (1953). The proof reduces the Halting Problem to the decision problem for S: assuming without loss of generality that the everywhere-undefined function is not in S, select an index e_0 with φ_{e_0} ∈ S. A machine M constructing program e_w (which runs machine M_0 on w and then executes e_0) belongs to S iff M_0 halts on w. Thus a decider for S yields a decider for Halting. Mechanically verified in Coq and Isabelle/HOL (Forster & Larchey-Wendling, 2019).

Sources

  • Rice, H. G. (1953). Classes of recursively enumerable sets of integers and their decision problems. Trans. Amer. Math. Soc., 74(2), 358-366.
  • Rogers, H. (1987). Theory of Recursive Functions and Effective Computability. MIT Press.
  • Forster, Y., & Larchey-Wendling, D. (2019). Certified Undecidability of Synthetic Computability Theory in Coq. CPP 2019.
