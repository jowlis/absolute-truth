F0100 supported

Tsirelson's bound states that for any bipartite quantum system in a tensor-product Hilbert space ℋ_A ⊗ ℋ_B, with dichotomic observables A₁, A₂ on ℋ_A and B₁, B₂ on ℋ_B having eigenvalues ±1, the quantum expectation value of the CHSH operator C = A₁⊗B₁ + A₁⊗B₂ + A₂⊗B₁ - A₂⊗B₂ satisfies |⟨C⟩| ≤ 2√2. This bound was derived by Boris S. Tsirelson (Cirel'son) in 1980.

Review note
The claim correctly formulates Tsirelson's bound (|⟨C⟩| ≤ 2√2) for quantum expectation values in bipartite tensor-product Hilbert spaces with dichotomic ±1 observables, accurately citing Tsirelson's 1980 paper.

Evidence

Tsirelson, 'Quantum generalizations of Bell's inequality', Lett. Math. Phys. 4, 93 (1980). The proof uses the operator norm: ⟨C⟩² ≤ 4 + [A₁,A₂]⊗[B₁,B₂] ≤ 8, giving |⟨C⟩| ≤ 2√2. Saturation is achieved by the singlet state |ψ⁻⟩ = (|01⟩ - |10⟩)/√2 with A₁=σ_z, A₂=σ_x, B₁=(σ_z+σ_x)/√2, B₂=(σ_z-σ_x)/√2.
