F0030 supported

In Peano Arithmetic (PA), multiplication distributes over addition on natural numbers (N) both on the left (∀a, b, c ∈ N, a * (b + c) = a * b + a * c) and on the right (∀a, b, c ∈ N, (a + b) * c = a * c + b * c), as mechanically verified in Lean 4, Coq, and Isabelle/HOL.
