F0099 supported

The CHSH inequality establishes that for any local hidden-variable theory, the CHSH correlation parameter C = A₁B₁ + A₁B₂ + A₂B₁ - A₂B₂ (where A₁, A₂ are Alice's measurement outcomes with settings 1,2 and B₁, B₂ are Bob's outcomes with settings 1,2, each taking values ±1) satisfies the bound |⟨C⟩| ≤ 2. This is the classical local-realist bound derived by Clauser, Horne, Shimony, and Holt (1969).

Review note
The claim accurately states the CHSH inequality, its classical local-realist bound |⟨C⟩| ≤ 2 for local hidden-variable theories, and cites the foundational 1969 paper by Clauser, Horne, Shimony, and Holt.

Evidence

Clauser, Horne, Shimony, Holt, 'Proposed Experiment to Test Local Hidden-Variable Theories', Phys. Rev. Lett. 23, 880 (1969). The bound follows from the fact that in any deterministic local hidden-variable model, each term A_i B_j takes value ±1, and the algebraic combination C = A₁(B₁+B₂) + A₂(B₁-B₂) can only equal ±2 for any assignment of ±1 values. Averaging over hidden variables preserves |⟨C⟩| ≤ 2.
