F0089 superseded

Berta et al. (2010) Entropic Uncertainty Relation with Quantum Memory (EUR-QM): For any bipartite state rho_{AB} shared between Alice (system A) and an observer holding quantum memory (system B), when Alice measures observable X (with eigenbasis {|x_i>}) or Z (with eigenbasis {|z_j>}), the conditional Shannon/von Neumann entropies satisfy S(X|B) + S(Z|B) ≥ log₂(1/c) + S(A|B), where S(X|B) = H(X|_B) is the conditional Shannon entropy of measurement outcomes given B, c = max_{i,j} |<x_i|z_j>| is the maximum overlap between the two measurement bases, and S(A|B) is the conditional von Neumann entropy of state A given quantum memory B.

Review note
The definition of the overlap parameter c is mathematically incorrect. The claim states c = max_{i,j} |⟨x_i|z_j⟩|, but the Berta et al. (2010) EUR-QM bound uses c = max_{i,j} |⟨x_i|z_j⟩|² (or equivalently the operator norm ‖√M_i √N_j‖² for POVMs). With the worker's definition, log₂(1/c) = -log₂(max|⟨x_i|z_j⟩|), whereas the correct bound requires -2 log₂(max|⟨x_i|z_j⟩|) = log₂(1/c²). This is a factor-of-2 error in the exponent that changes the numerical value of the bound. The claim must be restated with the correct definition of c.

Evidence

Established by Berta, Christandl, Colbeck, Renes, and Renner (Nature Physics 6, 659–662, 2010; arXiv:0909.0950), building on quantum memory side information and entropic uncertainty formulations. Proved via the quantum subadditivity of entropy and state purification.

Sources

  • M. Berta, M. Christandl, R. Colbeck, J. M. Renes, and R. Renner, 'The uncertainty principle in the presence of quantum memory', Nature Physics 6, 659 (2010); arXiv:0909.0950
