F0033 supported

In Peano Arithmetic / natural number arithmetic, for any dividend a ∈ N and positive divisor b ∈ N (b > 0), there exist unique quotient q ∈ N and remainder r ∈ N such that a = q * b + r with 0 ≤ r < b, as mechanically verified in Lean 4, Coq, and Isabelle/HOL.
Type
verifiable
Confidence
1.00
Refuted if
A counterexample pair (a, b) with b > 0 for which no such pair (q, r) exists or for which multiple distinct pairs (q1, r1) ≠ (q2, r2) satisfy a = q_i * b + r_i with r_i < b.

Evidence

Mechanically verified in Lean 4 (Init.Data.Nat.Basic: Nat.div_add_mod specifying m / n * n + m % n = m, and Nat.mod_lt specifying m % n < n for n > 0), Coq (Coq.Arith.PeanoNat: Nat.div_mod and Nat.mod_upper_bound), and Isabelle/HOL (HOL.Nat: div_mult_mod_eq and mod_less_divisor). Derived via well-founded induction on dividend a.
