CMP-001: The question 'Does P = NP?' (i.e., can every problem whose solution can be verified in polynomial time also be solved in polynomial time by a deterministic Turing machine?) is classified as 'verifiable-in-principle' (type: verifiable). While no polynomial-time algorithm for NP-complete problems has been found and the problem is one of the seven Millennium Prize Problems, a proof of P = NP (by exhibiting a polynomial-time algorithm for an NP-complete problem like 3-SAT) or P ≠ NP (by proving a superpolynomial lower bound) would constitute verification. The question is not verifiable-now because no proof exists in either direction, and it is not purely-conceptual because it has a definite mathematical answer within standard complexity theory.

Evidence

P vs NP is a Millennium Prize Problem (Clay Mathematics Institute). Relativizing barriers (Baker-Gill-Solovay 1975), natural proofs barrier (Razborov-Rudich 1997), and algebrization barrier (Aaronson-Wigderson 2008) show why standard techniques fail, but do not make the question conceptually undecidable. The question has a definite truth value in standard arithmetic (it is a Π₂ sentence).
