F0019 supported

Chaitin's Incompleteness Theorem and Algorithmic Information Limits: In any consistent, effectively generated formal theory T, there exists a constant c such that T cannot prove of any specific string x that its prefix Kolmogorov complexity K(x) exceeds c (K(x) > c); furthermore, Chaitin's halting probability Ω is Martin-Löf random and non-computable, with its initial n bits requiring at least n - O(1) bits of information to determine formally. Domain boundaries: Applies to Kolmogorov complexity over universal prefix-free Turing machines and effectively axiomatized theories; does not apply to non-effective theories, complexity relative to halting oracles, or establishing upper bounds on K(x) (which are computably enumerable).

Evidence

Proved by Gregory Chaitin (1974, 1975). If T could prove K(x) > c for arbitrarily large c, an algorithm could search for the first proof in T of K(x) > c and output x, generating a string of complexity > c using a program of size log(c) + O(1), creating a Berry-type contradiction for large c. Standard algorithmic information theory textbook consensus.

  • Li, M., & Vitányi, P. (2008). An Introduction to Kolmogorov Complexity and Its Applications (3rd ed.). Springer.
