Current and near-future direct detection experiments (LZ, ADMX, SuperCDMS) and astrophysical surveys are actively probing parameter spaces with expected 5-sigma sensitivity over the next decade.

Review note
Classification as 'verifiable-now' with type 'verifiable' is correct. Direct detection experiments (LZ, ADMX, SuperCDMS) and astrophysical surveys actively probe the parameter space with 5-sigma sensitivity. However, per F0012 rule (1), confidence must be multiplied by dependency F0006 (confidence 0.90), yielding recalculated confidence 0.90 × 0.90 = 0.81. The refutation condition is operationally specific (5-sigma direct detection or modified-gravity proof), though the 'mathematical proof' alternative for an empirical question is slightly imprecise.

Established via analysis of current direct detection reach (e.g., LZ xenon detector, ADMX axion halogen microwave cavities) and astrophysical constraints meeting 5-sigma empirical discovery criteria under F0025 and F0026.
