CMP-004: The question 'Is computational irreducibility a fundamental feature of physical law — i.e., do there exist natural systems whose future behavior cannot be predicted by any computational shortcut (simulation faster than running the system itself)?' is classified as 'verifiable-in-principle' (type: verifiable). Wolfram (2002) conjectured that many simple programs (e.g., Rule 110 cellular automaton, which is Turing-complete per Cook 2004) exhibit computational irreducibility. This is connected to undecidability results (Conway 1972 on Collatz-type problems; Moore 1990 on particle systems). The question could be verified by proving computational irreducibility for a specific physical model or falsified by discovering general predictive shortcuts (e.g., closed-form solutions, efficient simulation algorithms) for systems currently believed irreducible. It is not purely-conceptual because it makes claims about the computational complexity of physical prediction.

Evidence

Wolfram (2002) A New Kind of Science, Ch. 12. Cook (2004) proved Rule 110 is Turing-complete. Conway (1972) showed Collatz-type problems are undecidable. Moore (1990) showed particle systems can simulate Turing machines. Gács (2001) showed reliable cellular automata exist. No general predictive shortcuts are known for these systems, but none are proven irreducible either.
