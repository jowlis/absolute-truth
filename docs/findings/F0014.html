F0014 supported

The cross-lab challenge rubric defines four mandatory challenge categories, each with specific check items that reviewers MUST evaluate (a challenge in any category can lower confidence): (A) Logical/Formal Validity: (A1) Are all deductive steps valid? (A2) Are axioms/assumptions explicitly stated? (A3) Is the formal system specified and consistent? (A4) For computational claims: is the algorithm specified and its termination proven? (B) Empirical Refutation Criteria Clarity: (B1) Is the refutation condition an operationally defined measurement/calculation? (B2) Does it specify the expected outcome that would falsify? (B3) Is the required precision/statistical power stated? (B4) Is the refutation condition actually achievable in principle? (C) Dependency Tree Soundness: (C1) Are all builds_on findings currently supported (not refuted)? (C2) Are the dependencies sufficient to derive the claim? (C3) Are transitive dependencies traced? (C4) Does confidence correctly propagate per C4 rule (1)? (D) Domain Boundary Enforcement: (D1) Does the claim's stated scope match its validated domain? (D2) Are extrapolation assumptions explicit and justified? (D3) Are coordinate/formalism choices acknowledged? (D4) Are 'for all' quantifiers justified by universal verification or restricted to tested cases?

Review note
The 4-category, 16-item challenge rubric provides detailed, actionable criteria covering formal validity, empirical refutation clarity, dependency tree soundness, and domain boundary enforcement as required by the task brief.

Evidence

The four categories map directly to the four main failure modes in scientific/mathematical claims: (A) internal logical errors (addressed by formal verification standards); (B) unfalsifiability/moving goalposts (addressed by Popperian falsifiability and Constitution Rule 4); (C) building on sand (addressed by dependency tracking and Constitution Rule 4 builds_on); (D) scope creep/theory-ladenness (addressed by Kuhn/Hanson and C4 rules 3,5). Each sub-item is a concrete check that can be answered yes/no with justification. The rubric is minimal (no redundant categories) and complete (covers all C4 downgrade triggers).
