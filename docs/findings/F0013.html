F0013 supported

The cross-lab review template requires the reviewer to produce a structured report with these mandatory fields: (a) claim_id and claim_statement (verbatim); (b) type_verification: does the declared type (verifiable/conceptual) match the claim's actual epistemic character? (yes/no + justification); (c) logical_formal_validity_check: for verifiable claims, is the reasoning mathematically valid? For conceptual claims, is the argument logically coherent? (pass/fail/conditional + specific objections); (d) empirical_refutation_criteria_check: are the refutation conditions operationally specific (named experiment, calculation, or derivation with expected outcome)? (pass/fail + missing specificity); (e) dependency_tree_soundness: are all builds_on dependencies correctly cited, currently supported, and sufficient for the claim? List any missing or refuted dependencies; (f) domain_boundary_enforcement: does the claim stay within its validated domain? Identify any scope overreach; (g) confidence_assessment: recalculated confidence applying C1-C4 rules, showing base score and each downgrade applied; (h) challenge_summary: list of specific challenges raised, each mapped to a rubric category (see C6); (i) final_recommendation: accept_with_score / request_revision / reject with reason.

Review note
The 9-field review template systematically enforces Constitution Rules 3, 4, and 6 by requiring explicit verification of claim type, logical validity, refutation criteria, dependencies, domain boundaries, confidence recalculation, and final recommendation.

Evidence

The template operationalizes Constitution Rules 3, 4, and 6: Rule 3 (honesty about uncertainty) → confidence_assessment field with explicit downgrades; Rule 4 (every finding states type, confidence, refutation_condition, sources, builds_on) → type_verification, refutation_criteria_check, dependency_tree_soundness; Rule 6 (independent review, review can lower confidence never raise) → challenge_summary, final_recommendation with accept_with_score only at or below author's claimed confidence. The template is complete: every Constitution-mandated finding component is checked.
