In Peano Arithmetic (PA), multiplication on natural numbers (N) is commutative (∀a, b ∈ N, a * b = b * a) and associative (∀a, b, c ∈ N, (a * b) * c = a * (b * c)), as mechanically verified in Lean 4, Coq, and Isabelle/HOL.
