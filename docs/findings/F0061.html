CMP-007: The question 'Do one-way functions exist (i.e., functions easy to compute but hard to invert on average)?' is classified as 'verifiable-in-principle' (type: verifiable). The existence of one-way functions is equivalent to P ≠ NP (Impagliazzo 1995 'five worlds': Algorithmica, Heuristica, Pessiland, Minicrypt, Cryptomania). If one-way functions exist, then secure cryptography (pseudorandom generators, digital signatures, private-key encryption) is possible. The question could be resolved by: (a) proving P ≠ NP and constructing explicit one-way functions, or (b) proving P = NP (which would imply no one-way functions exist). It is not verifiable-now and not purely-conceptual — it is a concrete mathematical question with major practical implications.
Type
verifiable
Confidence
0.77
Refuted if
A proof that P = NP (which implies no one-way functions exist), OR a proof that one-way functions do not exist even assuming P ≠ NP (ruling out Minicrypt and Cryptomania, leaving only Pessiland), OR an explicit construction of a one-way function with a proof of its security (not based on unproven assumptions).

Review note
CMP-007 addresses one-way functions, classifies them as verifiable-in-principle (verifiable), assigns a justified confidence score (0.77), and provides clear refutation conditions.

Evidence

Impagliazzo (1995) 'A Personal View of Average-Case Complexity' (Structure in Complexity Theory). Håstad et al. (1999) showed one-way functions ⇔ pseudorandom generators. No unconditional one-way function is known; candidates (factoring, discrete log, lattice problems) rely on unproven hardness assumptions. The question is central to cryptography and average-case complexity.
