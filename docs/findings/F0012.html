F0012 supported

The following mandatory downgrades apply to ANY finding regardless of type, and are applied cumulatively (multiplicative on remaining confidence): (1) Unverified dependency: if the finding builds_on a finding with confidence < 0.95, multiply confidence by that dependency's confidence (propagates uncertainty); (2) Parameter imprecision: if a quantitative claim omits error bars, confidence intervals, or precision bounds → multiply by 0.70; (3) Scope overreach: if the claim's stated domain exceeds its validated domain (e.g., 'all energies' when tested only at GeV scale) → multiply by 0.60; (4) Inductive gap: if the inference from evidence to claim requires an unstated or unjustified assumption (e.g., uniformity of nature, typicality, naturalness) → multiply by 0.80 per such gap; (5) Unstated framing assumption: if the claim depends on a choice of formalism, coordinate system, or interpretation not acknowledged → multiply by 0.85; (6) Refutation condition vagueness: if the refutation_condition is not operationally checkable (no specified measurement, calculation, or logical derivation that would falsify it) → multiply by 0.75.

Review note
The mandatory multiplicative downgrades (unverified dependencies, parameter imprecision, scope overreach, inductive gaps, unstated framing assumptions, refutation condition vagueness) provide a non-arbitrary, mathematically monotonic mechanism for compounding uncertainty.

Evidence

Each rule addresses a known failure mode in scientific and mathematical claim-making: dependency propagation is standard in Bayesian networks and proof theory; parameter imprecision caused the OPERA superluminal neutrino error; scope overreach is the core error in many beyond-Standard-Model claims; inductive gaps are the problem of induction (Hume); framing assumptions underlie theory-ladenness of observation (Kuhn, Hanson); refutation condition vagueness makes claims unfalsifiable (Popper). Multiplicative combination ensures ordering independence and that multiple issues compound.

Sources

  • OPERA collaboration retraction (parameter imprecision case study)
  • Hume, An Enquiry Concerning Human Understanding (induction problem)
  • Kuhn, The Structure of Scientific Revolutions (theory-ladenness)
  • Popper, The Logic of Scientific Discovery (falsifiability)
  • F0006 (bounded agents, inductive underdetermination)
