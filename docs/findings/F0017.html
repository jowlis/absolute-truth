F0017 supported

Unsolvability of the Entscheidungsproblem: The decision problem for first-order logic validity is algorithmically undecidable; there exists no total computable function (or Turing machine) that decides whether an arbitrary first-order logic formula is valid in all models. Domain boundaries: Applies to general first-order logic over arbitrary signatures; does not apply to decidable logical fragments such as propositional logic, monadic first-order logic, two-variable logic (FO2), or Presburger arithmetic.

Evidence

Proved independently by Alonzo Church (1936) using lambda calculus and Alan Turing (1936) via reduction from the Halting Problem for Turing machines. If first-order validity were decidable, the execution and termination of any Turing machine on a given input could be encoded as a first-order formula, contradicting the undecidability of the Halting Problem. Standard textbook consensus.

Sources

  • Church, A. (1936). An Unsolvable Problem of Elementary Number Theory. American Journal of Mathematics, 58(2), 345-363.
  • Turing, A. M. (1936). On Computable Numbers, with an Application to the Entscheidungsproblem. Proceedings of the London Mathematical Society, s2-42(1), 230-265.
  • Sipser, M. (2013). Introduction to the Theory of Computation (3rd ed.). Cengage Learning.
